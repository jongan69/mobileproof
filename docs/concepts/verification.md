# What verification means

MobileProof never emits an unqualified “fully functional” guarantee.

Smoke verification proves the configured smoke flows passed. Capability
verification proves every declared applicable capability has current evidence.
Release verification additionally requires strict coverage, all declared
platforms, release checks, privacy scanning, and artifact-bound evidence.

An exclusion must include a reason, owner, and review date. An artifact,
source, configuration, requirement, or test change invalidates prior evidence.
Release attestations expire after seven days by default.
