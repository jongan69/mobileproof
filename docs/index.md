# MobileProof documentation

MobileProof combines application UI journeys, project checks, scenario setup,
postcondition assertions, privacy scanning, and an explicit capability ledger
into one reproducible verification result.

Start with the [quickstart](guide/quickstart.md), then define what your result
must prove in [the evidence contract](concepts/verification.md).
