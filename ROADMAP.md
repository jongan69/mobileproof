# Roadmap

## 0.1 — executable foundation

- Strict configuration and coverage contracts.
- Expo detection and scaffold generation.
- Local Maestro orchestration, Android/iOS discovery, reports, and redaction.

## 0.2 — application adapters

- Isolated source snapshots and persistent build fingerprints.
- Full bare React Native Xcode/Gradle discovery.
- Existing Maestro workspace migration.

## 0.3 — team workflows

- GitHub Android/iOS reusable workflows.
- Signed CI attestations and public evidence badges.
- Tested authentication, multi-user, offline, and permission recipes.

## 1.0

- Ten consecutive clean smoke runs for every first-party example/platform.
- Independent security review with no unresolved critical/high defect.
- Stable configuration, adapter, evidence, and result interfaces.
