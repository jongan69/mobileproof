# Security policy

Report vulnerabilities privately through GitHub Security Advisories. Do not
open a public issue containing an exploit, secret, private application log, or
customer data.

Supported versions are the latest minor release and the immediately preceding
minor release. Critical fixes may be released outside the normal schedule.

MobileProof executes project-owned commands and adapters with the permissions
of the invoking user. Review configuration changes like source code. The CLI
does not upload telemetry or artifacts unless a configured CI step does so.
